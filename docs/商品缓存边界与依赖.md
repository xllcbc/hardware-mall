# 商品缓存边界与依赖

## 目标

商品域缓存统一由 `ProductCacheService` 收口。业务服务不再自行拼接缓存 key、设置 TTL 或声明失效目标。

缓存只保存中性商品数据，不保存某个用户或用户等级专属的最终价格。用户身份裁剪在缓存读取完成后，由 `PricingRuleService` 和纯函数 `PriceService.resolveUnitPrice` 完成。

## 模块职责

```text
ProductCacheService
  商品缓存 key、TTL、搜索关键词规范化
  sku:info 批量读取、缺失回填、拿锁后 double-check
  product:list / product:search / product:recommend / product:detail 读取
  商品查询缓存的有界锁等待和并发回源退化

SkuService
  调用 ProductCacheService 批量读取 SKU
  补齐 sku:stock、按 SKU 有界 singleflight
  过滤已删除 SKU
  对外提供 Map<Long, Sku>

SpuService
  组装商品列表、搜索、推荐、详情的中性数据
  使用 UserContext + PricingRuleService + PriceService 生成当前用户价格视图

PricingRuleService
  等级分类倍率查询、矩阵读写和完整性校验
  维护 pricing:level / pricing:retail-level-id 缓存

CartService / OrderService
  只调用 SkuService
  不接触缓存 key、RedisUtil 或 loader

ProductCacheInvalidationListener
  同步处理 SKU/SPU 元数据与聚合缓存 EVICT

StockCacheEventListener
  异步且按提交顺序处理 sku:stock EVICT
  失效使用与库存重建相同的按 SKU 锁
  失败时写入库存清除补偿集合
```

## 缓存 Key

| Key | 内容 | TTL |
| --- | --- | --- |
| `sku:info:{skuId}` | SKU 基础信息，不包含库存 | 240 秒 + 0–60 秒抖动 |
| `sku:stock:{skuId}` | SKU 库存，Cache-Aside 回填 | 5 分钟兜底 |
| `product:detail:v5:{spuId}` | SPU、规格、原始 SKU 中性数据 | 240 秒 + 0–60 秒抖动 |
| `product:list:v5:{categoryId}:{page}:{limit}:{status}` | 商品列表批发基价中性区间 | 240 秒 + 0–60 秒抖动 |
| `product:search:v3:{keywordHash}:{categoryId}:{page}:{limit}:{status}` | 搜索结果批发基价中性区间 | 240 秒 + 0–60 秒抖动 |
| `product:recommend:v5` | 推荐商品批发基价中性区间 | 240 秒 + 0–60 秒抖动 |
| `pricing:level:{levelId}` | 该等级的全部分类倍率 | 240 秒 + 0–60 秒抖动 |
| `pricing:retail-level-id` | 零售等级 ID | 240 秒 + 0–60 秒抖动 |

搜索关键词先执行 `trim`、小写化和 Unicode NFKC 规范化，再计算 SHA-256。原始关键词不进入 Redis key。

## 读取边界

### 商品列表

```text
UserProductController
-> SpuService
-> ProductCacheService
-> PricingRuleService.rateFor(levelId, categoryId, excludeDiscount)
-> PriceService.resolveUnitPrice(basePrice, rate)
-> ProductListVO
```

### 商品详情

```text
UserProductController
-> SpuService
-> ProductCacheService.getProductDetail
-> ProductSkuVO
-> 实时补齐库存
```

`/api/user/product/{id}/skus` 复用 `product:detail:v5:{spuId}`，不直接查询 SKU 表。

### 购物车和订单

```text
CartService / OrderService
-> SkuService.getSkuMapByIds
-> ProductCacheService.getSkusByIds
-> RedisUtil.multiGet(sku:info:*)
-> 缺失 SKU 单次批量回源并回填
-> 批量补齐 sku:stock
-> PricingRuleService.rateFor
-> PriceService.resolveUnitPrice
```

## 失效依赖

| 数据变更 | 必须失效 |
| --- | --- |
| SKU 创建、价格修改、删除、复活 | 商品监听器 EVICT：`sku:info:{skuId}`、`product:detail:v5:{spuId}`、`product:list:v5:*`、`product:search:v3:*`、`product:recommend:v5` |
| SKU 库存字段变化 | 库存监听器 EVICT：`sku:stock:{skuId}` |
| 订单、支付、取消、退款库存变化 | 库存监听器 EVICT：`sku:stock:{skuId}` |
| SPU 名称、图片、状态、分类、价格、折扣开关修改 | `product:detail:v5:{spuId}`、`product:list:v5:*`、`product:search:v3:*` |
| SPU 推荐状态或推荐商品内容变化 | 普通 SPU 缓存，以及 `product:recommend:v5` |
| 等级矩阵修改、填充、复制 | 只失效 `pricing:level:{levelId}`，不失效商品缓存 |
| 等级停用、启用、删除 | 失效 `pricing:level:{levelId}` 与 `pricing:retail-level-id`，不失效商品缓存 |
| 用户等级变化 | 不失效商品缓存，只失效用户 Token |
| 购物车、订单写入 | 不失效商品缓存 |

商品元数据统一发布 `ProductCacheInvalidationEvent`，库存变化统一发布
`StockCacheEvent`。库存补偿集合为：

```text
stock:cache:evict:failed
```

商品监听器同步执行：

```java
@TransactionalEventListener(
    phase = TransactionPhase.AFTER_COMMIT,
    fallbackExecution = true
)
```

数据库事务回滚时不会触发商品缓存失效。

库存监听器通过专用单线程执行器异步执行，保证同一 SKU 的事件不乱序。库存读取 miss 时查询数据库并回填 Redis；Redis 只用于展示和预检查，下单仍以数据库原子扣减为准。

商品查询缓存使用有界锁等待，默认上限 500ms。等待超时后直接回源数据库且不写缓存，避免锁异常导致请求无限挂起。

批量 SKU 获取在拿到锁后再次执行 `multiGet`，只回源仍然缺失的 SKU；抢锁超时允许直接查库，但不得写缓存。

库存缓存失效和重建共用按 SKU 的锁。未命中读取采用有界 singleflight，失效超时进入库存补偿集合，不能把旧库存写回缓存。

商品缓存失效失败必须记录 Micrometer 指标和告警；当前不引入 outbox 或持久失效队列。价格相关商品缓存最长陈旧 300 秒。

定价缓存同样使用 `AFTER_COMMIT` 事件同步失效，但不复用商品缓存 key。
失效与重建共用同一把锁且等待有上限；失败只记录日志，最长由 300 秒 TTL 兜底。
定价缓存专属指标与告警暂不采用。发布时必须主动清理旧 `pricing:*` key。

## 维护规则

1. 新增商品缓存读取入口时，必须通过 `ProductCacheService`。
2. 新增 SKU 或 SPU 元数据写路径时发布 `ProductCacheInvalidationEvent`。
3. 新增库存变化写路径时发布 `StockCacheEvent`，v1 只允许 EVICT。
4. 商品缓存不得保存用户等级专属价格。
5. `PriceService.resolveUnitPrice` 必须保持纯函数，不注入 Redis、Mapper 或缓存服务。
6. 倍率修改只清理定价缓存，商品缓存继续复用中性批发基价区间。
7. 商品缓存 key 版本变更时，旧版本 key 等待自然过期或手动清理。
8. 价格相关商品缓存必须遵守 300 秒硬上限和 500ms 有界锁等待。
9. 库存缓存和批量 SKU 缓存必须使用有界 singleflight，超时可退化为直接查库但不得写缓存。
