## 一、接口概述

### 1.1 接口基础信息

| 项目 | 说明 |
|------|------|
| 基础URL | `http://api.hardware-mall.com` (开发环境：`http://localhost:8080`) |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 认证方式 | Bearer Token (JWT) |

### 1.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 1.3 分页响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 100,
    "size": 20,
    "current": 1
  }
}
```

### 1.4 订单状态码

| status | statusText | 说明 |
|--------|------------|------|
| 1 | 待付款 | 订单创建，等待支付 |
| 2 | 待发货 | 已支付，等待发货 |
| 3 | 已发货 | 已发货，运输中 |
| 4 | 已完成 | 已确认收货 |
| 5 | 已取消 | 订单已取消 |
| 6 | 退款中 | 退款处理中 |
| 7 | 已退款 | 退款完成 |

## 三、商品模块（SPU + SKU）

### 3.1 商品分类列表

**接口路径**：`GET /api/category/list`

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "name": "锁具",
      "icon": "🔐",
      "sortOrder": 100,
      "children": []
    }
  ]
}
```

### 3.2 商品列表（SPU列表）

**接口路径**：`GET /api/product/list`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页条数，默认20 |
| categoryId | long | 否 | 分类ID |
| keyword | string | 否 | 搜索关键词 |

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "id": 1,
        "categoryId": 4,
        "name": "防盗门锁 C级",
        "subtitle": "家用防盗门锁心",
        "images": ["https://xxx.com/lock1.jpg"],
        "originalPrice": 299.00,
        "minPrice": 199.00,
        "maxPrice": 259.00,
        "salesCount": 52,
        "status": 1
      }
    ],
    "total": 100,
    "size": 20,
    "current": 1
  }
}
```

**说明**：
- `minPrice` / `maxPrice`: 该SPU下所有SKU的价格区间
- 商品列表按SPU维度展示，显示最低价

### 3.4 管理端SPU列表

**接口路径**：`GET /api/admin/product/list`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页条数，默认20 |
| categoryId | long | 否 | 分类ID |
| status | int | 否 | 状态：1-上架，0-下架 |
| keyword | string | 否 | 搜索关键词 |

### 3.5 创建SPU商品

**接口路径**：`POST /api/admin/product`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| categoryId | long | 是 | 分类ID |
| name | string | 是 | 商品名称 |
| subtitle | string | 否 | 副标题 |
| description | string | 否 | 详细描述 |
| images | string[] | 是 | 图片URL列表 |
| originalPrice | decimal | 否 | 原价 |
| status | int | 否 | 状态，默认1 |
| isRecommend | int | 否 | 是否推荐，默认0 |

### 3.6 更新SPU商品

**接口路径**：`PUT /api/admin/product/{id}`

### 3.7 删除SPU商品

**接口路径**：`DELETE /api/admin/product/{id}`

### 3.8 更新SPU状态

**接口路径**：`PUT /api/admin/product/{id}/status`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| status | int | 是 | 状态：1-上架，0-下架 |

### 3.9 管理端SKU管理

#### 3.9.1 创建SKU

**接口路径**：`POST /api/admin/sku`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| spuId | long | 是 | SPU ID |
| specs | object[] | 是 | 规格组合 `[{"templateId":1,"itemId":1,"name":"颜色","value":"金色"}]` |
| price | decimal | 是 | 价格 |
| stock | int | 是 | 库存 |
| image | string | 否 | SKU图片 |
| status | int | 否 | 状态，默认1 |

#### 3.9.2 更新SKU

**接口路径**：`PUT /api/admin/sku/{id}`

#### 3.9.3 删除SKU

**接口路径**：`DELETE /api/admin/sku/{id}`

#### 3.9.4 更新SKU库存

**接口路径**：`PUT /api/admin/sku/{id}/stock`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| stock | int | 是 | 库存数量 |

#### 3.9.5 批量生成SKU（笛卡尔积）

**接口路径**：`POST /api/admin/spu/{id}/generate-skus`

**说明**：根据分类的规格模板和规格项，自动生成SKU的笛卡尔积组合。

## 五、购物车模块

### 5.1 购物车列表

**接口路径**：`GET /api/cart/list`

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "cartId": 1,
      "productId": 1,
      "skuId": 1,
      "productName": "防盗门锁 C级",
      "productImage": "https://xxx.com/lock_gold.jpg",
      "spec": "[{\"name\":\"颜色\",\"value\":\"金色\"}]",
      "price": 199.00,
      "quantity": 2,
      "subtotal": 398.00,
      "minPrice": 199.00,
      "maxPrice": 259.00
    }
  ]
}
```

**说明**：
- `productId` 实际是 SPU ID
- `spec` 是 SKU 的规格组合（JSON字符串）
- `minPrice` / `maxPrice` 是同一 SPU 下的价格区间

### 5.2 添加购物车

**接口路径**：`POST /api/cart`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| skuId | long | 是 | SKU ID |
| quantity | int | 是 | 数量，默认1 |

### 5.3 更新购物车数量

**接口路径**：`PUT /api/cart/{id}`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| quantity | int | 是 | 数量 |

### 5.4 删除购物车商品

**接口路径**：`DELETE /api/cart/{id}`

### 5.5 清空购物车

**接口路径**：`DELETE /api/cart`

## 六、订单模块（用户端）

### 6.1 创建订单

**接口路径**：`POST /api/order/create`

**请求参数**：

```json
{
  "items": [
    { "skuId": 1, "quantity": 2 },
    { "skuId": 3, "quantity": 1 }
  ],
  "addressId": 1,
  "logisticsId": 1,
```

### 6.3 订单详情（用户端）

## 十二、图片上传

### 12.1 上传商品图片

**接口路径**：`POST /api/admin/product/images`

**请求格式**：`multipart/form-data`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | file | 是 | 图片文件 |

**上传要求**：
- 文件格式：jpg、png、gif、webp
- 文件大小：不超过 10MB

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "url": "https://xxx.com/products/xxx.jpg"
  }
}
```
