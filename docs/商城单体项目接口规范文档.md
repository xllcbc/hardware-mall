## 一、接口概述

### 1.1 接口基础信息

| 项目 | 说明 |
|------|------|
| 基础URL | `http://localhost:8080`（以下路径均为相对路径，生产环境经 Nginx 反代） |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 认证方式 | Bearer Token (JWT) |

### 1.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 1.3 分页响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 100,
    "size": 20,
    "current": 1
  }
}
```

### 1.4 订单状态码

| status | statusText | 说明 |
|--------|------------|------|
| 1 | 待付款 | 订单创建，等待支付 |
| 2 | 待发货 | 已支付，等待发货 |
| 3 | 已发货 | 已发货，运输中 |
| 4 | 已完成 | 已确认收货 |
| 5 | 已取消 | 订单已取消 |
| 6 | 退款中 | 退款处理中 |
| 7 | 已退款 | 退款完成 |
| 8 | 退款申请中 | 用户已申请退款，等待管理员审核 |
| 9 | 退款失败 | 退款未成功，可重试 |

### 1.5 支付状态码（payment_record）

| status | 说明 |
|--------|------|
| 0 | 待支付 |
| 1 | 已支付 |
| 2 | 已关闭 |
| 3 | 已退款 |
| 4 | 退款中 |

**接口路径**：`GET /api/category/list`

**响应示例**：
```json

  "data": [
    {
      "id": 1,
      "name": "锁具",
      "icon": "🔐",
      "sortOrder": 100,
      "children": []
    }
```

### 3.2 商品列表（SPU列表）

**接口路径**：`GET /api/product/list`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页条数，默认20 |
| categoryId | long | 否 | 分类ID |
| keyword | string | 否 | 搜索关键词 |

**响应示例**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [

        "id": 1,
        "categoryId": 4,
        "name": "防盗门锁 C级",
        "subtitle": "家用防盗门锁心",
```

- `minPrice` / `maxPrice`: 该SPU下所有SKU的价格区间
- 商品列表按SPU维度展示，显示最低价

|--------|------|------|------|

| description | string | 否 | 详细描述 |

**接口路径**：`PUT /api/admin/product/{id}/status`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| status | int | 是 | 状态：1-上架，0-下架 |

### 3.9 管理端SKU管理

| 接口 | 路径 |
|------|------|
| SKU 列表（按 SPU 分页） | `GET /api/admin/sku/list?spuId=&page=&limit=` |
| SKU 详情 | `GET /api/admin/sku/{id}` |
| 某 SPU 下 SKU 列表 | `GET /api/admin/sku/spu/{spuId}` |
| 批量统计各 SPU 的 SKU 数 | `GET /api/admin/sku/counts?spuIds=1,2,3` |

#### 3.9.1 创建SKU

**接口路径**：`POST /api/admin/sku`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| spuId | long | 是 | SPU ID |
| specs | object[] | 是 | 规格组合 `[{"templateId":1,"itemId":1,"name":"颜色","value":"金色"}]` |
| price | decimal | 是 | 价格 |
| stock | int | 是 | 库存 |
| image | string | 否 | SKU图片 |
| status | int | 否 | 状态，默认1 |

#### 3.9.2 更新SKU

**接口路径**：`PUT /api/admin/sku/{id}`

#### 3.9.3 删除SKU

**接口路径**：`DELETE /api/admin/sku/{id}`

#### 3.9.4 生成SKU预览（笛卡尔积）

**接口路径**：`POST /api/admin/sku/generate/{spuId}`

**说明**：根据分类的规格模板和规格项，返回 SKU 笛卡尔积组合的**预览**，确认后由前端调用创建接口保存。

## 六、订单模块（用户端）

### 6.1 创建订单

**接口路径**：`POST /api/user/order/create`

**请求参数**：

```json
{
  "items": [
    { "skuId": 1, "quantity": 2 },
    { "skuId": 3, "quantity": 1 }
  ],
  "addressId": 1,
  "logisticsId": 1,
  "deliveryType": 2,
  "buyerRemark": "请小心轻放"
}
```

**说明**：
- `items`: 商品列表，基于 SKU 而非 SPU
- `addressId`: 收货地址ID
- `logisticsId`: 物流方式ID（自提可空）
- `deliveryType`: 发货方式：2-同城配送，4-用户自提

### 6.2 获取下单 Token

**接口路径**：`GET /api/user/order/token`

**说明**：用于下单幂等防重。

### 6.3 订单列表（用户端）

**接口路径**：`GET /api/user/order/list`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认1 |
| limit | int | 否 | 每页条数，默认20 |
| status | int | 否 | 订单状态筛选 |

### 6.4 订单详情（用户端）

**接口路径**：`GET /api/user/order/{id}`

### 6.5 取消订单

**接口路径**：`PUT /api/user/order/{id}/cancel`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| reason | string | 否 | 取消原因 |

### 6.6 申请退款

**接口路径**：`PUT /api/user/order/{id}/apply-refund`

**说明**：仅「待发货」「已发货」状态可申请，订单进入「8-退款申请中」，等待管理员审核。

### 6.7 确认收货

**接口路径**：`PUT /api/user/order/{id}/receive`

### 6.8 确认收货（微信发货管理校验）

**接口路径**：`PUT /api/user/order/{id}/receive-verify`

**说明**：接入微信发货管理后，确认收货需通过微信侧校验。

## 十二、图片上传

**请求格式**：`multipart/form-data`，字段名 `file`；限制 jpg/png/gif/webp，单个不超过 10MB。

| 接口 | 路径 | 说明 |
|------|------|------|
| 上传商品图 | `POST /api/admin/upload/product` | 按分类归档到 OSS |
| 上传头像（管理端） | `POST /api/admin/upload/avatar` | |
| 上传 Banner | `POST /api/admin/upload/banner` | |
| 上传头像（用户端） | `POST /api/user/upload/avatar` | |

**成功响应**：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "url": "https://xxx.com/products/xxx.jpg"
  }
}
```

> 图片替换/删除随 SPU、SKU 的更新与删除操作同步处理（软删 SKU 时同步删除 OSS 文件）。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orderId | long | 是 | 订单ID |

**说明**：创建支付记录并调用微信 JSAPI 下单，返回小程序端拉起支付所需参数。

### 13.2 支付结果回调

**接口路径**：`POST /api/user/pay/callback`

**说明**：微信支付异步通知，验签后确认支付成功。应答需返回 `{"code":"SUCCESS"}`；不 ACK 微信会重复通知。

### 13.3 退款结果回调

**接口路径**：`POST /api/user/pay/callback/refund`

**说明**：微信退款异步通知。退款成功推进「退款中 → 已退款」并回补库存；失败/异常保持退款中并告警，由定时对账兜底。

### 13.4 查询支付记录

**接口路径**：`GET /api/user/pay/query/{orderId}`
