# 五金商城微信小程序 - 设计规范

## 项目概述

- **项目名称**: 五金商城微信小程序 (Hardware Mall Mini Program)
- **版本**: v2.0
- **设计日期**: 2026-03-31
- **目标**: 重新设计商城界面，解决历史 Bug，实现品牌旗舰风格

---

## 1. 设计风格：品牌旗舰风

### 1.1 视觉定位

打造一个有品质感、专业的五金商城小程序。不同于传统电商的廉价感，通过轻奢金色点缀和大图展示，塑造高端品牌形象。

## 10. API 接口规范

### 10.1 接口基础

```javascript
// 基础配置
BASE_URL: 'http://localhost:8080/api'
CONTENT_TYPE: 'application/json'

// 请求头
Authorization: Bearer {token}

// 响应格式
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 10.2 接口列表

| 接口 | 方法 | 路径 | 说明 |
|-----|------|------|------|
| 登录 | POST | /user/login | 微信登录 |
