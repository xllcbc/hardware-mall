**日期**: 2026-05-06
**前提**: 租用轻量云服务器 + 申请个体户执照 + Docker Compose 单机部署

## 一、部署架构

单台轻量云服务器（2核2G），通过 Docker Compose 编排全部服务，Nginx 统一对外暴露 HTTPS。

```
┌──────────────────────────────────┐
│     轻量云服务器 (2核2G)          │
│                                  │
│  ┌──────────┐ ┌──────┐ ┌──────┐ │
│  │  MySQL   │ │Redis │ │Rabbit│ │
│  │  (3306)  │ │(6379)│ │(5672)│ │
│  └──────────┘ └──────┘ └──────┘ │
│       ↑           ↑         ↑    │
│  ┌────┴───────────┴─────────┴──┐ │
│  │    Spring Boot Backend      │ │
│  │         (端口 8080)          │ │
│  └─────────────┬───────────────┘ │
│                │                 │
│         ┌──────┴──────┐          │
│         │  Nginx:80/443│          │
│         │              │          │
│         │ /api/* → backend:8080  │
│         │ /*     → admin静态文件  │
│         └──────┬──────┘          │
└────────────────┼─────────────────┘
                 │ HTTPS
    ┌────────────┼────────────┐
    │            │            │
┌───┴───┐  ┌───┴───┐  ┌───┴──────┐
│ 管理端  │  │ 微信   │  │  小程序   │
│(浏览器) │  │ 服务器  │  │ (uni-app) │
└─────────┘  └───────┘  └──────────┘
```

## 二、安全审计与修复

### 已发现漏洞

#### P0（必须修复）

| # | 问题 | 位置 | 风险 |
|---|------|------|------|
| 1 | OSS AccessKey 硬编码 | `application.yml:75-76` | AK 泄露可被用于恶意上传/下载，产生巨额账单 |
| 2 | 微信 Secret 硬编码 | `application.yml:71` | 泄露后可伪造微信登录 |
| 3 | 数据库密码 `123456` | `application.yml:12` | 极弱密码 |
| 4 | 管理员密码 `123456` | `application.yml:67` | 极弱密码 |
| 5 | RabbitMQ 默认密码 `guest/guest` | `application.yml:39-40` | 默认凭证 |
| 6 | JWT 密钥为示例值 | `application.yml:62` | `your-256-bit-secret-key-change-in-production` |
| 7 | 所有密钥已在 Git 历史中 | backend 仓库 commit 记录 | 历史记录中可找回明文密钥 |
| 8 | `/api/admin/**` 无角色权限检查 | `JwtInterceptor.java` + `admin/` 控制器 | 普通用户 Token 可访问所有管理端接口 |
| 9 | 缺少根目录 `.gitignore` | 根目录 | `.env`、`application-prod.yml` 无 git 排除规则 |

#### P1（高优先级）

| # | 问题 | 位置 | 风险 |
|---|------|------|------|
| 10 | RuntimeException 处理器暴露内部错误详情 | `GlobalExceptionHandler.java:44` | `return Result.error(e.getMessage())` 向客户端泄漏异常信息 |
| 11 | 生产环境打印所有 SQL 语句 | `application.yml:53` | `StdOutImpl` 在日志/控制台输出含用户敏感数据的 SQL |
| 12 | CORS 仅允许 localhost | `WebMvcConfig.java:30-36` | 部署到服务器后小程序和管理端均无法跨域访问 |
| 13 | MySQL 使用 root 账号 | `application.yml:11` | 未遵循最小权限原则 |

#### P2（中优先级）

| # | 问题 | 位置 | 风险 |
|---|------|------|------|
| 14 | 日志级别为 debug | `application.yml:83` | 生产环境应使用 info 或 warn |
| 15 | 无 Actuator 健康检查 | 未引入 | 无法监控服务存活状态 |
| 16 | 管理员密码明文比较 | `AdminAuthController.java:36` | 配置文件内密码明文存储（作为配置项尚可接受，但密码强度和文件安全需保证） |

### 修复措施

1. **密钥环境变量化**: 全部密钥改用 `${ENV_VAR}` 占位符，真实值存入 `.env` 文件，`.env` 加入 `.gitignore`
2. **密钥轮换**: 在阿里云 RAM 创建子账号替换主账号 OSS AK/SK；重置微信 Secret；用 `openssl rand -base64 32` 生成新 JWT 密钥
3. **角色权限**: 实现 `@RequireAdmin` 注解，在拦截器链中校验 role=2 方可访问 `/api/admin/**`
4. **管理员强密码**: 改为 16 位以上随机密码
5. **异常处理**: RuntimeException handler 返回通用错误提示，不返回 `e.getMessage()`
6. **多环境配置**: 拆分为 `application-dev.yml` / `application-prod.yml`，生产环境关闭 SQL 日志、日志级别改为 info
7. **CORS 修复**: 允许域名改为环境变量配置，支持生产环境实际域名
8. **数据库安全**: 创建专用 MySQL 账号（非 root），分配最小权限；RabbitMQ 修改默认密码
9. **根目录 .gitignore**: 添加 `.env`、`application-prod.yml`、`*.local` 的排除规则

## 三、微信小程序企业认证流程

### 背景

- 小程序重新认证 300 元（一次性）

## 四、管理端安全方案

多设备远程访问 + 仅自己使用，采用三层防护。

| 防护层 | 措施 | 配置方式 |
|--------|------|----------|
| 第一层 | Nginx **HTTP Basic Auth**，访问 `/admin` 时浏览器弹出额外用户名/密码框 | `nginx.conf` 中 `auth_basic` + `.htpasswd` |
| 第二层 | Nginx **URL 密钥参数校验**，`?key=32位随机字符串` 不匹配直接返回 403 | `nginx.conf` 中 `if ($arg_key != "...") { return 403; }` |
| 第三层 | 管理端**强密码登录** + 登录限流（60秒内最多 5 次尝试，已有 `@RateLimit`） | 后端 AdminAuthController |

> 不知道密钥参数的人连管理端登录页面都看不到，加上 Basic Auth 弹框和强密码，三重保护足以防止陌生人闯入。

## 五、域名与 SSL

### 需要域名

微信小程序后台强制要求配置合法域名（`request` 合法域名、`uploadFile` 合法域名等），必须是已备案的 HTTPS 域名。管理端使用同一域名下的 `/admin` 路径即可。

### 步骤

| 步骤 | 内容 | 耗时 |
|------|------|------|
| 1 | 阿里云/腾讯云购买域名（`.cn` / `.com`，约 50 元/年） | 即时 |
| 2 | 提交域名备案（工信部 ICP 备案） | 15-20 工作日 |
| 3 | 备案通过后，申请免费 SSL 证书（Let's Encrypt / Certbot / 阿里云免费证书） | 即时 |
| 4 | 微信小程序后台 → 开发管理 → 服务器域名 → 配置 request/uploadFile/downloadFile 合法域名 | 即时 |

> 域名备案是整个流程的最长瓶颈（15-20 天），建议与阶段 2（微信小程序企业化）并行推进。

## 八、非功能性需求

- **性能**: 页面加载 < 3 秒，API 响应 < 1 秒（99% 情况），支撑同时 10 用户在线
- **安全**: HTTPS 强制，密钥全部环境变量化，生产环境不输出敏感日志
- **可用性**: 目标 95% 可用（允许非高峰维护窗口），数据库每日自动备份到 OSS
- **兼容性**: 管理端兼容 Chrome/Edge/Safari 最新版，小程序兼容微信 8.0 以上
